# راهنمای شروع گفتگوی تازه با Claude (پروژه هدیما)

لازم نیست قانون‌های پروژه را در پیام بنویسید: Claude در شروع هر گفتگو `CLAUDE.md` را خودش می‌خواند (زبان فارسی، شاخه، انتشار خودکار، تست) و اسکیل‌های قالب/افزونه را هنگام نیاز. فقط **خود کار** را خوب توضیح دهید.

## الگو
```
سلام. روی پروژه هدیما کار می‌کنیم.

کار: [در یک جمله: چه می‌خواهید]
کجا: [صفحه یا بخش سایت، یا منوی پیشخوان؛ مثلا «صفحه محصول، زیر دکمه خرید»]
الان چطور است: [وضع فعلی یا مشکل؛ اگر خطاست، متن خطا]
باید چطور شود: [نتیجه دلخواه]
نمونه: [عکس صفحه، لینک صفحه سایت، یا سایتی که شبیهش را دارد — اختیاری]
محدودیت: [چیزی که نباید عوض شود — اختیاری]

اول تحلیل کن و پیشنهاد بده، بعد از تأیید من انجام بده.
(یا: انجام بده.)
```

## نمونه‌ها
**رفع مشکل**
```
سلام. روی پروژه هدیما کار می‌کنیم.
کار: قیمت محصول در موبایل به هم ریخته.
کجا: صفحه محصول متغیر، موبایل (آیفون).
الان: قیمت قبلی و قیمت تخفیف‌خورده روی هم می‌افتند (عکس پیوست).
باید: زیر هم و خوانا باشند، مثل نسخه دسکتاپ.
انجام بده.
```

**امکان تازه**
```
سلام. روی پروژه هدیما کار می‌کنیم.
کار: نشان «ارسال رایگان» روی کارت محصولات بالای ۵ میلیون تومان.
کجا: فروشگاه، دسته‌ها و اسلایدرهای صفحه اصلی.
باید: از پیشخوان قابل روشن/خاموش باشد و مبلغ را خودم تعیین کنم.
اول تحلیل کن و پیشنهاد بده.
```

**بررسی و پیشنهاد**
```
سلام. روی پروژه هدیما کار می‌کنیم.
کار: سرعت صفحه اصلی را بررسی کن و بگو چه چیزهایی کندش می‌کند.
فقط گزارش بده، فعلا چیزی را تغییر نده.
```

## نکته‌ها
- **هر گفتگو یک کار.** گفتگوی کوتاه و متمرکز دقیق‌تر است و توکن کمتری مصرف می‌کند.
- **عکس بفرستید.** برای مشکل ظاهری، یک عکس از چند خط توضیح بهتر است.
- **کار بزرگ: «اول تحلیل کن».** پیش از تغییر نقشه را می‌بینید و می‌توانید اصلاحش کنید.
- **قانون تازه:** «یادت باشه از این به بعد …» — Claude آن را ثبت می‌کند تا گفتگوهای بعدی هم بدانند.
- **ادامه کار قبلی:** «ادامه بخش ۷۱» یا اسم کار — تاریخچه در `HODIMA-AUDIT.md` است.
- **فقط بررسی پیش از انتشار:** `/release check`.
- لازم نیست بنویسید «تست کن» یا «در گیت‌هاب آپلود کن»؛ خودکار است و در پایان گزارش فارسی می‌گیرید.
