# پیج اسپید (PageSpeed) هدیما — کارهای انجام‌شده، اندازه‌گیری‌ها و کارهای باقی‌مانده

این فایل خلاصه یک‌جای همه کارهای سرعت سایت (hodhodli.com) است. جزئیات فنی هر مرحله در `HODIMA-AUDIT.md` (بخش‌های ۱۷۲ تا ۱۸۰) است؛ اینجا فقط «چه شد، چقدر، چه مانده».

تنظیمات مربوط در پیشخوان: **قالب هدیما ← پیج اسپید** (گزینه‌های کد آمار، jQuery، تصویر کارت‌ها) و **قالب هدیما ← تنظیمات ویدئو** (دامنه پخش ویدیو و پادکست).

## یافته‌های ثابت (در همه اجراها)
- هاست سالم است (TTFB ≈ ۱۷۰–۲۱۰ms)؛ CLS همه صفحه‌ها < ۰٫۰۰۶؛ Render-blocking تقریبا صفر.
- `gtag.js` ۱۸۰KB (۷۲KB استفاده‌نشده) در ثانیه‌های اول با تصویر LCP رقابت می‌کند ← گزینه «بعد از اولین تعامل» (پیش‌فرض خاموش؛ تصمیم کاربر).
- فایل‌های سنگین محتوا (کار کاربر/لایت‌اسپید، نه کد): `Cover-500x500.png` ۳۱۴KB؛ JPG پوستر ویدیوها (۹۱ و ۱۰۶KB)؛ WebP تصویر اصلی محصول ۸۷KB برای ۵۰۰px.
- هر صفحه ۵ تا ۷ فایل فونت (۱۵۴–۱۹۲KB) می‌گیرد؛ Light (۳۰۰) فقط فوتر.

## کارهای باقی‌مانده (تصمیم کاربر)
1. زمان بارگذاری کد آمار ← «بعد از اولین تعامل».
2. تبدیل PNG/JPGهای سنگین به WebP و «WebP Quality» لایت‌اسپید حدود ۷۵–۸۰.
3. وزن Light فوتر ۳۰۰ ← ۴۰۰ (یک فایل ۳۱KB از همه صفحه‌ها؛ فوتر کمی ضخیم‌تر) و ادغام وزن‌های ۶۰۰/۵۰۰.
4. اندازه‌گیری مقاله (آدرس مقاله لازم است) و تکرار اندازه‌گیری بعد از به‌روزرسانی.
5. پوستر ویدیو (`hook_video`): دیرتر لود کردن بدون JS ممکن نیست؛ بعد از WebP شدن تصمیم‌گیری.

## درس‌ها (دوباره نیفت)
- سایت و pagespeed.web.dev از محیط ابری بسته است («Connection reset» از سمت هاست)؛ فقط سرور گوگل به سایت می‌رسد، پس اندازه‌گیری با **PageSpeed API و کلید شخصی** (فقط روی PageSpeed Insights API محدود؛ کلید را در چت ننویس و بعد از کار عوض کن).
- لایت‌اسپید تصویر را تنبل می‌کند مگر `data-no-lazy="1"` (یا `data-skip-lazy`، کلاس `skip-lazy`) داشته باشد (سورس `media.cls.php`). تصویر بالای صفحه همیشه این را بگیرد.
- حذف CSS ووکامرس بی‌مصرف ظاهر را عوض کرد؛ `content-visibility` برای فوتر/محصول در نویز بود ← هر دو رد شد.
- `sizes` را با عرض واقعی در Chromium بسنج (`getBoundingClientRect` در ۱۴ عرض)؛ فرمول باید همیشه ≥ عرض واقعی باشد.
- برای دانستن اینکه کدام عنصر کدام فایل فونت را می‌خواهد: `CSS.getPlatformFontsForNode` در CDP.
