# پیج اسپید (PageSpeed) هدیما — کارهای انجام‌شده، اندازه‌گیری‌ها و کارهای باقی‌مانده

این فایل خلاصه یک‌جای همه کارهای سرعت سایت (hodhodli.com) است. جزئیات فنی هر مرحله در `HODIMA-AUDIT.md` (بخش‌های ۱۷۲ تا ۱۸۰) است؛ اینجا فقط «چه شد، چقدر، چه مانده».

تنظیمات مربوط در پیشخوان: **قالب هدیما ← پیج اسپید** (گزینه‌های کد آمار، jQuery، تصویر کارت‌ها) و **قالب هدیما ← تنظیمات ویدئو** (دامنه پخش ویدیو و پادکست).

## درس‌ها (دوباره نیفت)
- CSS حیاتی (۳.۸.۰): stylesheetهای async را یک‌جا فعال کن (رسیدن نامرتب = چیدمان میانی و CLS)؛ `load` منتظر preload نیست؛ preload با media ناهمخوان دانلود نمی‌شود؛ در حذف قانون تکراری *آخرین* را نگه دار؛ همیشه با CSS کُند و نسخه ZIP بسنج. با لایت‌اسپید (۳.۸.۱) پیوندها را پیش از ترکیب preload نکن — ترکیب دور زده می‌شود و ده‌ها فایل با اولویت بالا فونت/LCP را عقب می‌اندازند؛ فایل ترکیبی نهایی را در `litespeed_buffer_finalize` async کن و با لایت‌اسپید واقعی بسنج. جابه‌جایی‌ای که فقط روی سایت زنده هست: `?hodima_ccss=1&hodima_ccss_debug=1` و PageSpeed API با `category=best-practices` ← `errors-in-console` (۳.۸.۲).
- سایت و pagespeed.web.dev از محیط ابری بسته است («Connection reset» از سمت هاست)؛ فقط سرور گوگل به سایت می‌رسد، پس اندازه‌گیری با **PageSpeed API و کلید شخصی** (فقط روی PageSpeed Insights API محدود؛ کلید را در چت ننویس و بعد از کار عوض کن).
- لایت‌اسپید تصویر را تنبل می‌کند مگر `data-no-lazy="1"` (یا `data-skip-lazy`، کلاس `skip-lazy`) داشته باشد (سورس `media.cls.php`). تصویر بالای صفحه همیشه این را بگیرد؛ `loading="eager"` و `fetchpriority` به‌تنهایی کافی نیست (بنر اسلایدر و استوری‌ها با همین دو صفت تنبل شده بودند — ۳.۷.۸).
- `target-size` لایت‌هاوس (axe) اندازه خود عنصر را می‌سنجد، نه `::before` بزرگ‌شده؛ کنترل کوچکی که روی لینک دیگری است (نقطه روی بنر) باید خودش ۲۴px باشد (`padding` + `background-clip: content-box`).
- قاعده `label-content-name-mismatch`: `aria-label`/`aria-labelledby` باید متن دیدنی کل عنصر را در خود داشته باشد (کارت لینک‌دار با تاریخ/زمان مطالعه ← نام از خود محتوا).
- حذف CSS ووکامرس بی‌مصرف ظاهر را عوض کرد؛ `content-visibility` برای فوتر/محصول در نویز بود ← هر دو رد شد.
- `sizes` را با عرض واقعی در Chromium بسنج (`getBoundingClientRect` در ۱۴ عرض)؛ فرمول باید همیشه ≥ عرض واقعی باشد.
- برای دانستن اینکه کدام عنصر کدام فایل فونت را می‌خواهد: `CSS.getPlatformFontsForNode` در CDP.
