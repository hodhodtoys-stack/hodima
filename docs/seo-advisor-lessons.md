# درس‌های ۸ پروژه برای بازسازی دستار سئو (مرحله الف)

تاریخ: ۱۲ آبان ۱۴۰۵ (۳ نوامبر ۲۰۲۶). فقط تحلیل؛ هیچ کدی عوض نشده.
مجوز: SEOnaut، SEOCORE، SiteOne، FreeCrawl، open-seo-crawler = **MIT** (الگو و ایده آزاد). Yoast، The SEO Framework، Rank Math = **GPL** (فقط ایده و عدد؛ کد کپی نشود).

## ۲) درس‌های ساختاری
1. **یک کاتالوگ واحد** (FreeCrawl: «a new check reaches every report without a second list to maintain»؛ SEOnaut: فهرست مرکزی `GetAllReporters`). ما حداقل **سه فهرست کد جدا** داریم: کاتالوگ (`advisor-issues.php`)، گروه‌های چیپ (`HODIMA_SEO_ADVISOR_CRAWL_GROUPS`) و بخش‌های نمره (`SCORE_CATEGORIES`)، به‌علاوه آستانه‌های پراکنده در `advisor-drafts.php` و `advisor-crawl.php`.
2. **هر قاعده = یک واحد کوچک** با شناسه، شدت، شرط، «چه کنم»، و **یک فایل آزمون با دو حالت (دارد/ندارد)** (SEOnaut). موتور فقط ۱۰۲ خط است.
3. **قاعده تک‌صفحه‌ای جدا از چندصفحه‌ای** (SEOnaut): تکراری و یتیم باید همه صفحه‌ها را با هم ببینند.
4. **شدت در یک نقشه مرکزی** با توضیح صادقانه «این قضاوت است، استاندارد قطعی نیست» (FreeCrawl). سه سطح: بحرانی = ایندکس/خزش را می‌شکند؛ هشدار = بهینه نیست؛ اطلاع = سلیقه‌ای.
5. **هر ایراد متن «چه کنم» خودش را دارد** (SEOCORE: `recommendation` + `evidence`؛ FreeCrawl: `ISSUE_ADVICE`؛ SiteOne: هر کسر نمره یک `fix`).

## ۳) درس‌های دقت (مهم‌ترین؛ ریشه ۱۰ چت)
1. **حد «گزارش» جدا از حد «نظری» است** (open-seo-crawler): سقف عنوان ۵۸۰ ولی گزارش از ۶۲۰؛ چون «میانه عنوان‌هایی که از ۵۸۰ گذشته‌اند ۵۹۰ است و اگر از خود حد گزارش بدهیم صفحه به صفحه ایراد کاذب می‌گیریم». ما از خود ۵۸۰ و ۲۹۰ گزارش می‌دهیم و حاشیه نداریم.
2. **«عنوان کوتاه» جدی نیست:** SEOnaut < ۲۰ نویسه؛ FreeCrawl < ۳۰ نویسه (هشدار)؛ Yoast < ۴۰۰px نمره ملایم + گزینه `allowShortTitle`؛ SEO Framework (۴ پله: ۲۰۰/۲۸۰/۵۲۰/۶۰۰px) درجه‌بندی، نه ایراد؛ SEOCORE اصلاً «کوتاه» ندارد. ما: زیر ۲۹۰px = **قرمز** (bad).
3. **یک ایراد در دو واحد دوبار گزارش نشود** (open-seo: پیکسل فقط وقتی شمار نویسه ساکت است).
4. **هر ایراد استثنا دارد و ثبت می‌شود با مدرک:**
   - soft-404: اگر کلمه > ۳۵۰ یا «archives» در عنوان باشد نه.
   - صفحه بن‌بست: PDF/ویدیو/فید و خطا و آدرس غیر http حساب نمی‌شوند («۸ از ۲۰ مورد اول نویز بود»).
   - «تکراری» (SEOnaut): فقط صفحه ۲۰۰، HTML، canonical خودش، زبان یکسان.
   - ردیف دامنه‌های دیگر کنار گذاشته می‌شود.
5. **آزمون ثابت‌ها (invariant):** `test_data_correctness.py` می‌گوید «هر آیتم فهرست هر ایراد باید شرط همان ایراد را داشته باشد» («مثبت کاذب ریدایرکت-در-سایت‌مپ را می‌گرفت»). **باگ `/contact-us/` ما دقیقاً شکستن همین ثابت است:** پیش‌نویس پیشنهادی باید از خود تشخیص رد شود (۲۶۸px < کف ۲۹۰).
6. **کالیبره هر زبان جدا:** SEO Framework برای فارسی ضریب پیکسلی **۷۶۰/۹۱۰ ≈ ۰٫۸۳۵** دارد. یعنی «۵۸۰ ثابت» برای فارسی بدون سنجش واقعی صحیح نیست. ما با وزیرمتن اندازه می‌گیریم؛ مرجع واقعی = عکس نتیجه واقعی گوگل (هنوز نداریم).

## ۴) درس‌های نمره
- SiteOne: سقف هر نوع ایراد (۲٫۵) و سقف هر بخش (۵)، تا **یک ایراد فراگیر کل نمره را صفر نکند**؛ پله‌ای برای ۴۰۴ (۱ ← ۰٫۵، ۲ تا ۵ ← ۱، ۶ تا ۲۰ ← ۱٫۵، بیشتر ← ۲).
- SEOCORE: ضریب شدت × وزن قاعده، میانگین وزنی بخش‌ها.
- **ما:** کسر = ضریب × (صفحه‌های دارای ایراد ÷ همه) × ۱۰۰ بدون سقف. «عنوان کوتاه» روی همه صفحه‌ها (ضریب ۲) = کسر ۲۰۰ ← بخش «عنوان و متا» صفر. **تأییدشده از کد `advisor-score.php`؛ روی سایت واقعی سنجیده نشده.**

## ۵) ایرادهای تازه (بدون تکرار؛ از کجا)
- **درون صفحه (SEOnaut/open-seo):** چند `<title>`/`<meta description>`، متای تکراری، canonical (چندگانه، نسبی، به ریدایرکت/خطا/noindex، اختلاف HTML و هدر)، `lang` (نبود/نامعتبر)، `viewport`، `id` تکراری، meta داخل body، ترتیب تیترها.
- **خاص open-seo (ارزشمند):** **canonical یا robots داخل body را گوگل نادیده می‌گیرد** (موقعیت در HTML خام)؛ **آدرس زباله** (`undefined`/`null` در URL؛ «روی ۴۱۲ صفحه یک سایت دیده شد»)؛ حد ۲ مگابایت HTML گوگل؛ «همه لینک‌های ورودی از صفحه‌های ایندکس‌نشدنی»؛ ماسک‌کردن محتوای بی‌اثر (کامنت/template/script) پیش از شمارش.
- **FreeCrawl:** عنوان جایگزین («Untitled»)، عنوان تک‌کلمه‌ای، صفحه خالی، محتوای تکراری دقیق.
- **لینک و منبع (SEOnaut):** حلقه ریدایرکت، بن‌بست، لینک بیرونی خراب/ریدایرکت، `localhost`، تصویر بدون ابعاد/سنگین/alt بلند، آدرس زیرخط/فاصله/چند اسلش، فرم روی http.
- **سطح سایت از دیتابیس (Rank Math؛ همان «لایه دیتابیس»):** `blog_public` (سایت از گوگل پنهان است)، ساختار پیوند یکتا، شعار سایت. ارزان و **بحرانی**؛ در دستار ندیدم.
- **نه (برای ما بی‌ربط):** کلمه کلیدی و خوانایی (Yoast)، هوش مصنوعی، hreflang (سایت تک‌زبانه؛ تأیید کاربر لازم)، هدرهای امنیتی، بک‌لینک، Core Web Vitals (تصمیم کاربر: حذف).

## ۷) خلاصه تصمیم‌های پیشنهادی (برای مرحله ب)
1. فهرست کد واحد (کاتالوگ) + آزمون «دارد/ندارد» برای هر ایراد.
2. **آزمون ثابت:** هر پیش‌نویس باید از تشخیص همان ایراد رد شود؛ هر آیتم هر فهرست شرط ایرادش را داشته باشد.
3. «کوتاه» ← اطلاع (و از نمره/اولویت حذف)؛ «بلند» ← حد گزارش جدا از حد نظری (حاشیه).
4. سقف کسر نمره برای هر ایراد و هر بخش.
5. استثناهای ثبت‌شده برای هر ایراد با مدرک (مثل open-seo).
6. بررسی سطح سایت (`blog_public`…) و لایه دیتابیس.
7. کالیبره پیکسل با عکس واقعی نتیجه گوگل (فارسی).
