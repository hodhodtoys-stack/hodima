# ماژول «مشاور سئو» (Hodima SEO ۲.۵.۰ تا ۲.۵.۸)

تحویل کار برای گفتگوهای بعدی. جزئیات هر مرحله: `HODIMA-AUDIT.md` بخش‌های ۲۵۵ تا ۲۶۱. قانون‌های کلی پروژه: `CLAUDE.md`.

## خلاصه
با داده Search Console همین سایت (جستجوی وب، نه دیسکاور) برای هر صفحه می‌گوید چه کاری بیشترین کلیک اضافه را می‌آورد. **فقط پیشنهاد می‌دهد؛ چیزی را در سایت عوض نمی‌کند.** پیشخوان: «ابزارهای هدیما ← مشاور سئو» (`admin.php?page=hodima-advisor`) و کادر «مشاور سئو» داخل ویرایش نوشته/برگه/محصول/دسته (کنار سئوباکس). ماژول `advisor` در «ماژول‌های سئو» روشن/خاموش می‌شود.

## تصمیم‌ها و عددها
- بازه ۲۸/۹۰/۱۸۰ روز (پیش‌فرض ۹۰)؛ بازه قبلی هم‌اندازه برای افت؛ داده تا ۲ روز پیش (وقت اقیانوس آرام).
- آدرس صفحه = «مسیر یکسان‌شده» (بدون دامنه، پارامتر، #بخش؛ رمزگشایی‌شده؛ لاتین کوچک). رتبه صفحه با وزن نمایش میانگین می‌شود.
- فرصت: ≥ ۱٬۰۰۰ نمایش و نرخ کلیک کمتر از حد معمول رتبه (≤۲: ۲۵٪، ≤۳: ۱۴٪، ≤۵: ۹٪، ≤۷: ۵٫۵٪، ≤۱۰: ۳٫۵٪، بالاتر ۱٫۵٪). کلمه: ≥ ۳۰۰ نمایش. افت: کلیک قبلی ≥ ۵۰ و فعلی < ۷۰٪ آن. حداکثر ۶ پیشنهاد هر آدرس.
- «کلیک بالقوه» تخمین است (نه تضمین)؛ عدد صفحه = بزرگ‌ترین پیشنهاد (نه جمع).
- عنوان در فهرست = نام صفحه/H1 (نه عنوان سئو)، زنده خوانده می‌شود.
- لینک‌دهی: ۵ صفحه برتر (بیشترین نمایش گوگل) که متنشان آن عبارت را دارد و به صفحه لینک ندارند + «N دیگر». عنوان پیشنهادی فقط پیش‌نویس (کلمه + نام)؛ توضیح متا خودکار نوشته نمی‌شود.
- کادر ویرایش فقط برای مدیر و صفحه منتشرشده؛ فقط خواندنی؛ «بازگرداندن» لینک GET با nonce (کادر داخل فرم وردپرس است).

## اولین اجرای واقعی (۳ آبان ۱۴۰۵)
«داده ۹۰ روز اخیر گرفته شد؛ ۲۹۰ آدرس بررسی و برای ۴۷ آدرس پیشنهاد ساخته شد» — اتصال، دریافت، ذخیره و تحلیل روی سایت زنده کار کرد.

## مانده / کارهای بعدی (به ترتیب پیشنهاد)
1. **بررسی خودکار گیت‌هاب قرمز است:** مرحله Render (`ci-check.sh`) به‌خاطر ۵ آزمون `phone-tests.php` (فهرست لیدهای تلفنی: «جدول و هر دو لید»، «نمای جدید»، «جستجو با ارقام فارسی»، «جزئیات»، «جداساز چپ‌به‌راست») رد می‌شود؛ از پیش از مشاور سئو هم همین بود. علت اصلی پیدا نشده (احتمالا وابسته به تاریخ/زمان یا ارقام). Lint سبز است.
2. **اشکال قدیمی سئوباکس:** توضیح متای خودکار (`seobox_plain_text` ← `seobox_post_fallback_description`) متن تیتر و پاراگراف را بدون فاصله می‌چسباند («کلیپس پلومریامتن صفحه»). رفع و آزمون.
3. **مرحله ۷:** هشدار افت کلیک (پیشخوان، ابزارک) و خلاصه هفتگی ایمیلی با الگوی `discover-alerts.php`.
4. گزینه پیشخوان «حداقل نمایش» (`hodima_advisor_settings['min_impressions']` از قبل خوانده می‌شود)، و تنظیم جدول نرخ معمول.
5. قاعده «ایندکس نشده» (به API بررسی ایندکس نیاز دارد).
6. آزمون روی ویرایشگر کلاسیک و محصول ووکامرس واقعی؛ `tools/wp-harness/layout-rules.sh` برای صفحه مشاور؛ ارقام فارسی روی سایت.
7. اگر نوار ابزار/ردیف جمع‌شونده صفحه مشاور در صفحه دیگری هم لازم شد: به کیت `tools/ui-kit/` ببر (الان در `advisor-admin.css` است).
