# فایل‌های نصب هدیما (آخرین نسخه)

این پوشه همیشه آخرین نسخه قابل نصب قالب و افزونه‌ها را دارد (ساخته‌شده با `bin/build.sh`).

## دانلود
روی هر فایل کلیک کنید و در صفحه باز شده دکمه **Download** (یا «View raw») را بزنید:

| فایل | چیست | کجا نصب شود |
|---|---|---|
| `hodima.zip` | قالب | نمایش ← پوسته‌ها ← افزودن ← بارگذاری پوسته |
| `hodima-core.zip` | افزونه Hodima Core (اول این را نصب کنید) | افزونه‌ها ← افزودن ← بارگذاری افزونه |
| `hodima-seo.zip` | افزونه Hodima SEO | افزونه‌ها ← افزودن ← بارگذاری افزونه |
| `hodima-commerce.zip` | افزونه Hodima Commerce | افزونه‌ها ← افزودن ← بارگذاری افزونه |
| `hodima-media.zip` | افزونه Hodima Media | افزونه‌ها ← افزودن ← بارگذاری افزونه |

## به‌روزرسانی روی سایت
هنگام بارگذاری، وردپرس می‌پرسد نسخه فعلی جایگزین شود؛ «جایگزینی نسخه فعلی با بارگذاری‌شده» را بزنید. تنظیمات و داده‌ها پاک نمی‌شوند.
بعد از به‌روزرسانی، کش LiteSpeed (و کش مرورگر) را پاک کنید.
