# هدیما (Hodima)

قالب وردپرس فروشگاه عمده‌فروشی به همراه چهار افزونه. قالب فقط **نمایش** را بر عهده دارد. امکانات سئو، فروشگاه و رسانه در افزونه‌ها هستند، پس با تعویض قالب داده‌ها و امکانات از بین نمی‌روند.

| بسته | مسیر | کارکرد |
|---|---|---|
| **قالب Hodima** | `hodima/` | هدر و فوتر، قالب‌های صفحه، صفحه اصلی، قالب‌های ووکامرس، استایل‌ها، بهینه‌سازی، صفحه «تنظیمات هدیما» (لوگو، تماس، فوتر، Google Analytics) |
| **Hodima Core** | `plugins/hodima-core/` | کتابخانه مشترک و پیش‌نیاز بقیه افزونه‌ها: IP واقعی (سازگار با Cloudflare)، محدودیت نرخ، تشخیص ربات، موتور Canonical، محتوای محافظت‌شده |
| **Hodima SEO** | `plugins/hodima-seo/` | متاباکس سئو، اسکیما، سایت‌مپ، robots.txt، ریدایرکت‌ها، آدرس تمیز، خوشه‌های موضوعی، لینک‌سازی داخلی، IndexNow، Google Indexing API، llms.txt |
| **Hodima Commerce** | `plugins/hodima-commerce/` | تاریخ جلالی و شهرهای ایران، جستجوی زنده محصولات، فرم لید تلفنی، جدول مشخصات، حداقل مبلغ/تعداد سفارش، فیلدهای سفارشی محصول |
| **Hodima Media** | `plugins/hodima-media/` | استوری، ویدیو، اسلایدر، سیستم رسانه (ویدیو/پادکست/FAQ)، اعلان‌ها، باکس‌های بازشونده، جدول داینامیک |

## پیش‌نیازها
- WordPress 6.5 یا جدیدتر (برای `Requires Plugins`)
- PHP 8.4
- WooCommerce برای Hodima Commerce (بدون آن فقط فرم لید تلفنی فعال است)

## استاندارد کدنویسی
PHP 8.4، HTML5، CSS مدرن، JavaScript خالص (بدون jQuery).

پالت رنگ: `#25316a` · `#607bbd` · `#b6c2f3` · `#6a2b9a` · `#a341c8` (توکن‌ها در `hodima/assets/css/tokens.css`).

## ساخت فایل‌های نصب
```bash
bin/build.sh   # خروجی: dist/hodima.zip و dist/hodima-*.zip
```

## به‌روزرسانی سایتی که نسخه ۱ قالب را دارد
قبلا همه امکانات داخل قالب بود. اگر فقط قالب به‌روز شود، امکانات سئو، فروشگاه و رسانه تا نصب افزونه‌ها غیرفعال می‌شوند. **داده‌ها از بین نمی‌روند**، چون نام جدول‌ها، گزینه‌ها و متاها تغییر نکرده است.

1. از کل سایت (فایل‌ها و دیتابیس) نسخه پشتیبان بگیرید. بهتر است ابتدا روی استیجینگ امتحان شود.
2. قالب را به نسخه ۲ به‌روز کنید.
3. افزونه‌ها را به این ترتیب بارگذاری و فعال کنید: **Hodima Core**، بعد **Hodima SEO**، **Hodima Commerce** و **Hodima Media**.
   اگر افزونه‌ها زودتر از قالب فعال شوند مشکلی پیش نمی‌آید: تا وقتی نسخه ۱ قالب فعال است، افزونه‌ها ماژول‌هایشان را لود نمی‌کنند (وگرنه توابع دوبار تعریف می‌شدند و سایت از کار می‌افتاد) و یک پیام در پیشخوان نشان می‌دهند.
4. یک بار **تنظیمات ← پیوندهای یکتا ← ذخیره** را بزنید تا آدرس‌ها (سایت‌مپ، robots.txt، ویدیوها، llms.txt) بازسازی شوند.
5. کش (LiteSpeed/Cloudflare) را پاک کنید.
